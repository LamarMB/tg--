# Генератор документации на шкафы управления

Telegram-бот и утилита командной строки, которые по Excel-файлу строят PDF
в формате комплекта ВКС (А3, рамка и основная надпись по ГОСТ 2.104).

**Готово:**
- документ «Спецификация» (В4): титульный лист, спецификация элементов, клеммный план;
- схема Э3, часть 1: титульный лист и листы входов/выходов модулей ПЛК —
  контакты реле, кнопки, катушки, лампы, стрелки к клеммам, маркировка проводов,
  **перекрёстные ссылки катушка ↔ контакты проставляются автоматически**.

**Дальше:** силовые листы Э3 (ввод, автоматы, БП/ИБП, распределение 24 В),
листы коробок и шкафов (клеммы + кабели), сетевая схема.

## Как пользоваться

**Текстом.** Напишите боту, что в проекте: шифр, заказчик, модули ПЛК и что
висит на входах/выходах, реле, клеммники, спецификацию. Бот (через Claude API)
сам заполнит Excel и пришлёт PDF + этот Excel. Дальше можно править сообщениями:
«добавь реле 1K5 на выход B5», «замени автомат QF3 на 16А». Бот помнит проект
чата; `/new` — начать новый, `/project` — прислать текущий Excel.
Артикулы и производителей бот не выдумывает — чего не хватает, спросит.

**Через Excel.** `/template` — пустой шаблон, `/example` — пример. Заполнить
(подсказки — на листе «Инструкция») и прислать файлом — придёт PDF. Если в файле
ошибки, бот их перечислит. Присланный Excel тоже становится текущим проектом.

Для текста нужен ключ Claude API (console.anthropic.com → API Keys) в `.env`:
`ANTHROPIC_API_KEY=sk-ant-...`. Из России запросы к API идут только через VPN.

## Запуск на Windows

1. Установить Python 3.10+ с python.org (галочка «Add Python to PATH»).
2. Скопировать `.env.example` в `.env` и вписать `BOT_TOKEN=...`.
3. Запустить `run_bot.bat` (первый раз сам создаст окружение и поставит пакеты).

Бот работает, пока открыто окно. Белый IP и домен не нужны.

## Запуск на Linux / сервере

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN
.venv/bin/python bot.py
```

## Без бота

```bash
python cli.py examples/example_2196_SS1.xlsx       # -> examples/example_2196_SS1.pdf
python cli.py --template шаблон.xlsx                 # пустой шаблон
```

## Структура

```
bot.py                 Telegram-бот (только стандартная библиотека Python)
schemgen/assistant.py  разбор текста через Claude API (tool use -> JSON проекта)
schemgen/jsonio.py     проект <-> JSON (состояние чата в папке data/)
cli.py                 командная строка
schemgen/
  model.py             модель данных
  excel_io.py          чтение Excel, проверка, создание шаблона
  pen.py               рисование (reportlab), шрифт, перенос строк
  frame.py             рамка А3, боковая графа, основные надписи (формы 1 и 2а)
  document.py          сборка комплекта
  sheets/title.py      титульный лист
  sheets/spec.py       спецификация элементов
  sheets/terminals.py  клеммный план
  e3/                  схема Э3: модель, символы УГО, листы ПЛК, чтение Excel
assets/                логотип для основной надписи, шрифт
examples/              пример заполнения по шкафу ВКС.АСПУ.2196.СС1
tests/                 python -m unittest -v
```

## Шрифт

В образце — Tahoma. Если он есть в системе (Windows), используется он,
иначе — DejaVu Sans Condensed из `assets/fonts`. Свой шрифт:
переменная окружения `SCHEMGEN_FONT=путь\к\шрифту.ttf`.

## Логотип

`assets/logo.png` выводится в основной надписи титульного листа.
Заменить — положить свой файл с тем же именем.
